# 架构与技术选型

采用本地 Python 命令行程序，运行依赖为零。当前把已有剧本变为一致的生产数据，不需要 Web 框架、数据库或模型推理环境。未来界面可以调用相同核心函数。

## 当前模块

| 模块 | 公开入口 | 职责 |
| --- | --- | --- |
| `model.py` | `load_episode(path)` / `parse_episode(data)` | 读取、格式和引用校验，返回不可变对象 |
| `planner.py` | `build_plan(episode)` | 纯函数生成时间、提示词、台词与待办状态 |
| `exporter.py` | `export_bundle(plan, destination)` | 写完临时目录后整体移动，拒绝覆盖已有目录 |
| `cli.py` | `main(argv)` | 命令、成功提示、中文业务错误及退出码 |

核心规划不读写文件，不访问网络，不读取环境变量，不绑定模型厂商。新功能在需要时增加模块。

## 数据约定

- 输入 `schema_version: 1`；输出 `bundle_version: 1`。字段升级需显式迁移。
- ID 是稳定引用，名称只是展示文本。镜头 ID 在整集唯一。
- 内部统一使用整数毫秒，避免浮点累计漂移。
- 相同的规范化剧本得到相同输出；`source_sha256` 对内部规范化剧本计算，不包含时间戳或机器路径，不等于源文件字节哈希。
- `planned`、`pending` 不意味着生成成功；当前没有素材状态更新功能。
- 字幕按字数估时。每秒 6 字的提醒只是启发式，不是语音或平台标准。
- CSV 为 UTF-8 BOM；文本以 `= + - @` 开头时加单引号，避免被表格视为公式。JSON 保留原文本。

## 后续接入边界（尚未实现）

先接一家正式提供文档和适用授权的图片服务，完成单镜头的“提交、查询状态、下载、人工批准”。服务适配模块负责鉴权、超时、重试和错误归类，核心计划不读取服务商 SDK 类型。

| 接入 | 输入 | 输出与记录 |
| --- | --- | --- |
| 图片 | 镜头 ID、提示词、画幅、参考图、模型和参数 | 路径、任务 ID、真实参数、次数、费用（可得时）、审核状态 |
| 配音 | 台词 ID、文本、批准音色、声音参数 | 路径、实际时长、任务 ID、费用（可得时） |
| 合成 | 批准图片、测量后的音频、对齐字幕、输出规格 | 视频路径、日志、失败原因 |

这只是后续设计边界，不是已可调用的接口。不把网页按钮自动化当成稳定 API，不收集账号 Cookie。价格、额度、商用范围和地区可用性在选定供应商时核实，本版不预设单条成本。

付费调用前应显示任务数、重试上限和预算；缓存成功结果，只重试失败镜头。费用拿不到时保留“未知”，不能记成 0。先记录一次人工出片的实际支出，再确定默认限制。

## 暂缓方案

| 方案 | 原因 | 何时考虑 |
| --- | --- | --- |
| 本地 ComfyUI / 大模型 | 增加硬件和维护门槛 | 已确定效果、显存需求和使用频率 |
| FastAPI / 浏览器界面 | 先验证数据和制作闭环 | 输入方式成为主要阻碍时 |
| 数据库 / 队列 | 本地文件足以起步 | 多集并发、恢复或多人协作成为需求时 |
| 非公开剪映草稿接口 | 格式变化有兼容成本 | 有稳定、获准的接口及维护收益时 |
| 自动发布 | 需正式平台能力和授权 | 人工样片验证后独立评估 |

基础合成后续优先评估 FFmpeg；现阶段用剪映等工具人工剪辑。两者都是方向，不代表已接入。
