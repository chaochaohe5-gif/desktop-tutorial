# 剧本格式 v1

完整样本：[`examples/episode.json`](../examples/episode.json)。字段名保持英文，内容可用中文。

## 根对象

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| `schema_version` | 整数 | 必须为 `1` |
| `id` | 字符串 | 集 ID，例如 `episode-001` |
| `title` | 字符串 | 非空标题 |
| `aspect_ratio` | 字符串 | `9:16`、`16:9`、`1:1` 三选一 |
| `visual_style` | 字符串 | 全集画风，非空 |
| `negative_prompt` | 字符串 | 可选，默认空；服务是否支持另行核实 |
| `characters` | 数组 | 角色库，可为空 |
| `scenes` | 数组 | 至少一个场景，按时间顺序排列 |

对象拒绝未知字段和 JSON 重复键。文本首尾空格去除，连续空白变成单个空格。使用 UTF-8 JSON，支持 BOM。

ID 由 1–64 位字母、数字、下划线或短横线组成，首位为字母或数字。区分大小写，建议小写，不允许路径分隔符或 `..`。素材名带 `shot_` 前缀，避免裸 ID 成为系统保留文件名。

## 角色对象

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| `id` | 字符串 | 角色库内唯一；不能是 `narrator` |
| `name` | 字符串 | 展示名，非空 |
| `appearance` | 字符串 | 固定外观，非空 |
| `voice` | 字符串 | 声音方向，非空；不是服务商音色 ID |

## 场景对象

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| `id` | 字符串 | 全集场景 ID 唯一 |
| `location` | 字符串 | 地点、时间、天气等共享信息，非空 |
| `shots` | 数组 | 至少一个镜头，按播放顺序排列 |

## 镜头对象

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| `id` | 字符串 | **整集**镜头 ID 唯一 |
| `duration_seconds` | 数字 | 大于 0、不超过 3600 秒，最多 3 位小数；不接受字符串或布尔值 |
| `framing` | 字符串 | 景别、机位或构图，非空 |
| `visual` | 字符串 | 主要画面，非空 |
| `characters` | 字符串数组 | 出镜角色 ID，不重复，可为空 |
| `lines` | 数组 | 台词列表，可为空表示无台词镜头 |
| `sound` | 字符串 | 可选，默认空；只作指令，不生成音效 |

3600 秒是防止错误输入的程序上限，不是推荐时长。每句字幕至少分配 1 毫秒，过短镜头包含过多台词时拒绝。

## 台词对象

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| `speaker` | 字符串 | 已定义角色 ID，或 `narrator`（旁白） |
| `text` | 字符串 | 非空台词，不必再写角色名 |

说话角色可以不在当前出镜名单内，表示画外音，但仍需在角色库定义。

## 输出约定

媒体相对路径基于生产包目录：

- `images/shot_<镜头ID>.png`：图片预期路径。
- `audio/shot_<镜头ID>_line_<两位序号>.wav`：逐句音频路径，序号超过两位自然扩展。
- 时间用整数毫秒，从 `0` 开始；SRT 只包含台词，无台词镜头保留时间间隔。
- 全无台词时得到空 SRT 和只有表头的配音 CSV。

当前只规划媒体路径，不创建虚假图片或静音音频。再次 `build` 产生新的初始计划，不读取已有媒体或继承手改状态。

退出码：成功 `0`；参数错误、校验错误、读取或写入失败为 `2`。
