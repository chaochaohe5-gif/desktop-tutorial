# MVP 任务清单

目标是单人可维护、每步可人工验收的制作流程。任务先在此跟踪，创建 issue 时引用编号和验收记录，不依赖代码搜索索引。

## M0 · 离线生产包（本次交付）

- [x] T001：替换默认教程 README，明确能力及边界。
- [x] T002：版本化剧本、角色、场景、镜头、台词格式。
- [x] T003：实现 `validate` 和 `build`，零运行依赖。
- [x] T004：输出分镜、角色卡、提示词、配音台本、字幕草稿和发布检查。
- [x] T005：原创示例、跨平台启动脚本、测试和 CI 配置。

验收：示例得到 6 镜头 / 30 秒 / 8 文件；无台词镜头保留时间；非法输入报错；旧输出不被覆盖。CI 以 GitHub 检查页为准，配置存在不等于已经通过。

## M1 · 第一条人工样片（最高优先级）

- [ ] T101：确认故事和角色参考，按生产包制作图片与配音。
  - 验收：逐镜有可用素材，外观和声音经过人工确认。
- [ ] T102：剪辑、对齐字幕、完整观看修正，再人工发布一次。
  - 验收：有视频、制作问题记录和发布链接，不以播放量保证验收。
- [ ] T103：记录单集费用、重试次数和分步骤工时。
  - 验收：能指出最大瓶颈，决定先自动化哪个环节。

## M2 · 素材登记与单一生成服务

- [ ] T201：导入图片/音频，检查存在和格式，记录待审核/通过/返工。
  - 验收：缺图、损坏音频、漏镜头能报错；重新规划不丢失已登记素材。
- [ ] T202：选择并接入一家图片服务，支持参考图、查询和下载。
  - 依赖：T103、T201；先核实正式文档、地区、价格、授权。
  - 验收：单镜头可下载查看，失败有原因，无密钥进入日志。
- [ ] T203：任务缓存、重试上限、预算确认与支出记录。
  - 验收：不无提示地重复付费；超时和预算耗尽可停止，成功任务可复用。

## M3 · 配音与成片

- [ ] T301：接入正式 TTS，保存音色映射与每句真实时长。
  - 验收：角色声音一致，异常台词可单独重做，费用可记录。
- [ ] T302：根据音频重建字幕时间，支持人工修订。
  - 验收：无负时长、重叠、漏词或越过片尾，试听确认停顿。
- [ ] T303：FFmpeg 合成图片、音频、字幕与简单运动。
  - 依赖：T201、T301、T302。
  - 验收：缺素材拒绝渲染；样片无黑屏/断音；失败保存日志。

## M4 · 降低操作门槛

- [ ] T401：根据真实使用选择轻量 Web 界面，支持角色编辑与镜头排序。
  - 验收：不改核心数据契约，能完成编辑和生产包导出。
- [ ] T402：封面、简介及复盘记录交接文件。
  - 验收：人工可据此发布、回填链接并导出数据。
- [ ] T403：自然语言剧本辅助拆镜。
  - 验收：模型输出经过严格校验和人工审阅，错误结果不触发付费生成。

暂缓多供应商、本地 GPU、多人权限、自动登录/发布。扩展应说明解决了哪个已观察到的制作瓶颈。
